# Third-party software and assets

This project uses Next.js, React, React DOM, Motion, Tailwind CSS, TypeScript, Playwright, axe-core, and their dependencies. Their licenses remain applicable and are included in their installed npm packages. Use `package-lock.json` for the exact dependency inventory.

Manrope Variable and Space Grotesk Variable are locally served using the Fontsource packages. Both use the SIL Open Font License; the license texts are copied into `public/fonts/licenses/` so they accompany the exported website as well as the source.

The project image-slot placeholders and favicon were authored for this website. The sculptural hero is original AI-generated brand artwork, not professional game or product work. Its original file and generation prompt are in assets/. No stock imagery or old portfolio assets were used.

The résumé content belongs to Aditya Nair. The downloadable copy removes old portfolio references; the original source document is not altered.
